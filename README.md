Tools for people who drive a computer with a switch, their gaze or a single muscle, and for the teams whose interfaces have to hold up. Every animation below is the real software, captured frame by frame.


<br>

<sub>PRODUCT</sub>

### [designesy](https://github.com/LE-VAI/designesy-org)

<a href="https://www.designesy.org"><picture>
  <source media="(prefers-reduced-motion: reduce)" srcset="assets/loops/designesy.png">

Scores any URL against a published design contract: one grade, every check named, evidence you can cite. An MCP server, a GitHub Action, a stylelint plugin and a CLI.<br>

### [access-input](https://github.com/LE-VAI/access-input)

<a href="https://github.com/LE-VAI/access-input"><picture>
  <source media="(prefers-reduced-motion: reduce)" srcset="assets/loops/access-input.png">
